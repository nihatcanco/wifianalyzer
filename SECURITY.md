# Security

wifianalyzer shows data that anyone nearby can send: network names and everything else access points broadcast. If
you find a way to make the app misbehave through that data, or anything else that puts its users at risk, please
report it privately rather than in a public issue.

To report one, use **Report a vulnerability** on the repository's **Security** tab.

The app must never connect to anything, so a way to make it reach the network, directly or through the operating
system, counts as a vulnerability too.

Fixes go into the latest release.
